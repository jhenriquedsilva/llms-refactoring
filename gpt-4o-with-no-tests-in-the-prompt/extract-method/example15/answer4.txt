The provided code snippet has duplication in the `getGenericType` methods for the `Field` and `Parameter` objects. Both methods have almost identical logic for extracting the generic type. We can refactor this by extracting the common parts into a private method. Here’s the refactored class:

```java
package org.mockito.internal.util.reflection;

import java.lang.reflect.Field;
import java.lang.reflect.Parameter;
import java.lang.reflect.ParameterizedType;
import java.lang.reflect.Type;

public class GenericMaster {

    /**
     * Finds the generic type (parametrized type) of the field. If the field is not generic it returns Object.class.
     *
     * @param field the field to inspect
     */
    public Class<?> getGenericType(Field field) {
        Type generic = field.getGenericType();
        return resolveGenericType(generic);
    }

    /**
     * Resolves the type (parametrized type) of the parameter. If the field is not generic it returns Object.class.
     *
     * @param parameter the parameter to inspect
     */
    public Class<?> getGenericType(Parameter parameter) {
        Type generic = parameter.getParameterizedType();
        return resolveGenericType(generic);
    }

    /**
     * Resolves the generic type from a given Type. If the type is not generic it returns Object.class.
     *
     * @param generic the type to inspect
     * @return the resolved Class, or Object.class if not generic
     */
    private Class<?> resolveGenericType(Type generic) {
        if (generic instanceof ParameterizedType) {
            Type actual = ((ParameterizedType) generic).getActualTypeArguments()[0];
            if (actual instanceof Class) {
                return (Class<?>) actual;
            } else if (actual instanceof ParameterizedType) {
                // in case of nested generics we don't go deep
                return (Class<?>) ((ParameterizedType) actual).getRawType();
            }
        }
        return Object.class;
    }
}
```

- Extracted the common logic into a private method `resolveGenericType(Type generic)`.
- Modified the `getGenericType` method for `Field` to call `resolveGenericType` with `field.getGenericType()`.
- Modified the `getGenericType` method for `Parameter` to call `resolveGenericType` with `parameter.getParameterizedType()`. Note: Corrected `parameter.getType()` to `parameter.getParameterizedType()`, which is the proper way to get generics for parameters if intended.
  
This refactoring reduces code duplication and enhances readability and maintainability.
